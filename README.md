# Expense Tracker
A beginner-friendly Python application that helps users keep track of their daily expenses. The program allows users to add expenses, view expense history, and manage their spending records.

## Features

- Add new expenses
- View expense history
- Store expense records
- Calculate total expenses
- Simple command-line interface

## How It Works

1. The user enters expense details such as name and amount.
2. The program saves the expense data.
3. Users can view their previous expenses.
4. The program helps users keep track of their spending.

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Run the file:

python expense_tracker.py
